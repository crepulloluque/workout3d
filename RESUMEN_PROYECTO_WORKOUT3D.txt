│  OPCIÓN 2: ARTISAN SERVER                                                   │
│  1. Abrir terminal en c:\laragon\www\workout3d                              │

│  3. En otra terminal: npm run dev                                           │
│  4. Abrir navegador: http://localhost:8000                                  │

│  • Comando: php artisan migrate:fresh --seed                                │
